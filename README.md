# ✈️ Golobe: Побудова моделі прогнозування цін на готелі

Цей проєкт є частиною екосистеми **Golobe** — платформи для бронювання авіаквитків та готелів.
Мета роботи: розробити інтелектуальний модуль для прогнозування вартості проживання (ADR).

## 📊 Основні етапи проєкту:

1. **Збір та обробка даних:** Використано Hotel Booking Demand dataset (Kaggle). Виконано очищення від аномалій та обробку пропущених значень.
2. **EDA:** Проведено візуальний аналіз розподілу цін та кореляції ознак.
3. **ML Моделювання:** Порівняно два алгоритми:
   - Linear Regression (Baseline)
   - Random Forest Regressor
4. **Оцінка:** Моделі оцінювались за метриками MAE, RMSE та R² Score.

## 📁 Структура репозиторію:

- `Golobe_ML_Project.ipynb` — Jupyter Notebook з повним циклом розробки.
- `hotel_bookings.csv` — датасет для навчання.
- `Presentation_Golobe.pdf` — презентація проєкту.

## 🚀 Як запустити:

1. Клонувати репозиторій.
2. Встановити бібліотеки: `pip install pandas numpy matplotlib seaborn scikit-learn`.
3. Запустити Jupyter Notebook.
